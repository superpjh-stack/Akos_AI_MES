- 8개 1차 메뉴 고정 표시 (아이콘 + 텍스트 레이블)
- 현재 섹션의 2차 메뉴 자동 확장 (Accordion 방식)
- 역할 기반으로 접근 불가 메뉴는 렌더링에서 완전 제거 (시각적 노이즈 방지)
- 현장작업자 전용 모바일 모드: 하단 탭바로 전환 (FAT실행/공정이상/재고조회 3개 고정)

**사이드바 항목 구성**

```
[아이콘] 대시보드
[아이콘] 설계/BOM
         ├─ BOM 목록
         ├─ BOM 등록
         ├─ 부품 마스터
         ├─ 도면 관리
         └─ 변경 요청
[아이콘] 생산 관리
[아이콘] FAT 관리          ← 품질/현장작업자 고빈도 메뉴
[아이콘] 납품/SAT
[아이콘] AI Agent          ← 항상 상단 빠른 접근 제공
[아이콘] 원가/견적
[아이콘] 관리자            ← 관리자 역할에만 노출
```

```

│  [+] 빠른 작업       │
│  • BOM 등록         │
│  • FAT 시작         │
```

### 3.4 브레드크럼 (Breadcrumb)

**원칙:** 최대 4단계까지만 표시, 중간 단계 축약 처리

```
[패턴 1 - 표준 3단계]
대시보드 > FAT 관리 > FAT 결과/리포트

[패턴 2 - 깊은 4단계]
생산 관리 > 공정 관리 > 공정 이상 등록 > #ANO-2024-088

[패턴 3 - 컨텍스트 포함 (프로젝트 범위 설정 시)]
[PJT: 현대차 라인3] > FAT 관리 > FAT 실행 > 체크리스트

[패턴 4 - 모바일 축약]
```

**브레드크럼 인터랙션**
- 각 계층 클릭 시 해당 목록 화면으로 이동

- 프로젝트 컨텍스트 스위처: 브레드크럼 앞에 `[PJT명]` 칩으로 표시, 클릭 시 프로젝트 전환

## 4. 핵심 사용자 플로우

### Flow 1: BOM 등록 플로우 (설계자)

```
[트리거] 신규 수주 후 BOM 작성 요청

설계자
│
├─ 1. 대시보드 접속
│      → 알림: "BOM 작성 요청: PJT-2024-099"
│
├─ 2. 설계/BOM > BOM 등록 이동
│      → URL: /design/bom/new
│
├─ 3. 기본 정보 입력 (탭 1)
│      - 제품 코드 자동 채번 (시스템)
│      - 설비명, 고객사 선택 (드롭다운)
│      - 납기일 입력
│      - 프로젝트 연결
│
├─ 4. 부품 구성 트리 편집 (탭 2)
│      - 최상위 조립체 추가
│      - 하위 부품 드래그앤드롭 추가
│      - 부품 코드 검색 → 마스터에서 자동 단가 불러오기
│      → [AI 보조] 유사 BOM 자동 추천 (RAG 기반)
│
├─ 5. 도면 첨부 (탭 3)
│      - PDF/DWG 드래그앤드롭 업로드
│      - 버전 태그 입력 (v1.0)
│
├─ 6. 저장 (임시저장 or 검토 요청)
│      → [임시저장]: BOM 상태 = DRAFT
│      → [검토 요청]: 상태 = IN_REVIEW, PM에게 알림 발송
│
├─ 7. PM 검토/승인
│      - PM이 BOM 목록에서 IN_REVIEW 건 확인
│      - 코멘트 입력 후 [승인] or [반려]
│      → 승인 시: 상태 = APPROVED, 생산관리자에게 알림
│      → 반려 시: 설계자에게 재작업 알림
│
└─ 8. 완료
       - BOM 상태: APPROVED
       - 생산 오더 연결 가능 상태
       - 원가 자동 계산 트리거

[분기] 오류 발생 시:
  - 필수 입력값 누락 → 인라인 validation 메시지
  - 부품 코드 미등록 → "신규 부품 등록" 모달 팝업
  - 중복 BOM 감지 → 유사 BOM 목록 경고 표시
```

```
현장작업자 / 출하 담당
│
├─ 5. 포장/상차 완료 후 출하 처리
│      → URL: /delivery/shipment/{id}/complete
│      - 운송장 번호 입력
│      - 출하 사진 첨부
│      → 상태: SHIPPED, PM/경영진 알림
│
[SAT 단계 - 현장 설치 후]

PM + 품질담당자
│
├─ 6. 납품/SAT > SAT 계획 등록
│      → URL: /delivery/sat/new
│      - 현장 방문 일정
│      - SAT 체크리스트 선택
│
├─ 7. SAT 실행 (고객사 현장)
│      - 모바일로 SAT 체크리스트 수행
│      - 고객사 서명 (전자 서명)
│      → 상태: SAT_COMPLETED
│
├─ 8. SAT 결과 리포트 생성
│      → PDF 자동 생성
│      → 고객사 발송
│
경영진
│
└─ 9. 경영진 대시보드에서 납품 완료 확인
       → URL: /dashboard/executive
       - 매출 인식 가능 상태 업데이트
       - KPI: 납기 준수율 자동 반영
       - 월별 납품 실적 차트 업데이트
```

## 5. URL 구조 설계

**설계 원칙**
- RESTful 리소스 중심 설계 (명사 복수형 사용)
- 계층 관계는 URL 경로로 표현 (최대 3단계)
- 쿼리 파라미터: 필터, 정렬, 페이지네이션
- 액션은 URL에 포함하지 않음 (HTTP Method로 표현)
- 프론트엔드 SPA 라우팅 기준 (Streamlit 멀티페이지 or React)
