## 2. Epic별 사용자 스토리

### Epic 1. 설계 / BOM 관리

**Epic 목적:** 프로젝트 단위 BOM을 단일 진실의 원천(Single Source of Truth)으로 관리하고, 설계 변경 시 전 부서에 즉시 반영한다.

---

**US-1-01. BOM 등록 및 계층 구조 관리**

```
As a 설계자,
I want to 품목 코드·사양·소요량·단위를 포함한 다계층 BOM을
시스템에 직접 등록하고 Tree 뷰로 확인하고 싶다,
So that Excel 파일 없이도 정확한 자재 소요량을 산출할 수 있다.
```

- 세부 요건
  - 최대 10레벨 계층 BOM 지원
  - 동일 부품의 다수 상위 품목 참조(Phantom BOM) 지원
  - CSV/Excel 일괄 Import 기능 제공
  - 부품 코드 중복 검증 (등록 시 자동 경고)

---

**US-1-02. ECO (설계변경) 발행 및 이력 추적**

```
As a 설계자,
I want to 설계 변경 사유·변경 전후 사양·적용 프로젝트를 ECO 번호와 함께 등록하고,
관련 부서(생산·구매·품질)에 자동 알림을 발송하고 싶다,
So that 구버전 BOM으로 작업하는 사고를 원천 차단할 수 있다.
```

- 세부 요건
  - ECO 번호 자동 채번 (ECO-YYYYMM-NNN)
  - 변경 전/후 BOM 버전 diff 시각화
  - 알림 채널: 시스템 내 알림 + 이메일
  - ECO 승인 워크플로 (설계자 기안 → PM 승인)

---

**US-1-03. 프로젝트별 BOM 스냅샷 및 비교**

```
As a PM,
I want to 특정 시점의 BOM 스냅샷을 저장하고,
현재 BOM과 스냅샷을 비교하여 변경 내역을 확인하고 싶다,
So that 고객사 납품 버전과 현재 버전의 차이를 빠르게 파악하고
변경 관리 책임을 명확히 할 수 있다.
```

- 세부 요건
  - 스냅샷: 프로젝트 이정표(Milestone) 연동 자동 저장
  - 비교 결과: 추가/삭제/변경 항목 색상 구분 표시
  - PDF 출력 지원

---

**US-1-04. AI 기반 유사 BOM 추천**

```
As a 설계자,
I want to 신규 프로젝트 BOM 작성 시 유사한 과거 프로젝트 BOM을
AI가 추천해 주는 기능을 사용하고 싶다,
So that BOM 초안 작성 시간을 단축하고 누락 부품 오류를 줄일 수 있다.
```

- 세부 요건
  - RAG Agent가 과거 BOM 벡터 DB(pgvector) 기반 Top-3 유사 BOM 제시
  - 유사도 점수(%) 함께 표시
  - 추천 BOM → 현재 프로젝트 BOM으로 복사 기능

---

**US-1-05. 부품 소요량 자동 산출 및 구매 요청 연동**

```
As a 생산관리자,
I want to 확정 BOM 기준으로 프로젝트 전체 부품 소요량이
자동으로 산출되어 구매 요청서 초안이 생성되기를 원한다,
So that 수작업 소요량 계산 오류를 없애고 구매 리드타임을 단축할 수 있다.
```

- 세부 요건
  - 재고 차감 후 순 발주량 자동 계산
  - 우선순위 구분: 장납기 부품 자동 플래그
  - 출력 포맷: PDF / Excel 양식

---

### Epic 2. 생산 / 공정 관리

**Epic 목적:** 작업지시 발행부터 공정 완료까지 디지털화하여 공정 가시성을 확보하고, AI로 공정 이상을 사전 감지한다.

---

**US-2-01. 작업지시 발행 및 현장 수령 확인**

```
As a 생산관리자,
I want to 프로젝트별 공정 계획에 따라 작업지시를 시스템에서 발행하고,
현장작업자가 단말에서 수령 확인(서명)할 수 있기를 원한다,
So that 구두 지시로 인한 오작업과 책임 불명확 문제를 없앨 수 있다.
```

- 세부 요건
  - 작업지시서: 공정명, 대상 설비, BOM 버전, 도면 링크 포함
  - 현장 단말(터치스크린) 수령 서명 기능
  - 미수령 작업지시 30분 경과 시 생산관리자 알림

---

**US-2-02. 실시간 공정 진행률 대시보드**

```
As a PM,
I want to 프로젝트별 전체 공정의 계획 대비 실적을 간트차트와
퍼센트 게이지로 실시간 확인하고 싶다,
So that 납기 지연 위험을 조기에 감지하고 자원을 재배치할 수 있다.
```

- 세부 요건
  - 갱신 주기: 5분 이내
  - 드릴다운: 프로젝트 > 공정 > 작업자 단위
  - 지연 공정: 빨간색 하이라이트 + 지연일 자동 계산
  - 모바일 반응형 지원

---

**US-2-03. 공정 이상 감지 및 알림 (XGBoost/RF 예측)**

```
As a 생산관리자,
I want to OPC-UA·MQTT로 수집된 설비 센서 데이터를 AI 모델이
실시간으로 분석하여 이상 징후를 감지하고 알림을 받고 싶다,
So that 설비 고장이나 공정 불량이 발생하기 전에 선제적으로 조치할 수 있다.
```

- 세부 요건
  - 수집 프로토콜: OPC-UA (PLC), MQTT (IoT 센서)
  - 예측 모델: XGBoost + Random Forest 앙상블
  - 알림 임계값: 이상 확률 70% 초과 시 즉시 알림
  - 알림 채널: 시스템 팝업 + 현장 경광등 연동 (선택)

---

**US-2-04. 재작업 지시 자동 생성**

```
As a 생산관리자,
I want to 불량 판정된 공정에 대해 재작업 범위·담당자·일정이
자동으로 제안되는 재작업 지시서를 생성하고 싶다,
So that 불량 발생 후 재작업 계획 수립에 소요되는 하루치 시간을 1시간 이내로 단축할 수 있다.
```

- 세부 요건
  - 불량 판정 즉시 재작업 지시 초안 자동 생성
  - 담당자 가용 여부(일정 캘린더) 연동
  - 재작업 완료 후 원 작업지시에 이력 연결

---

**US-2-05. 자재 부족 사전 경보**

```
As a 생산관리자,
I want to 향후 2주 공정 계획 기준으로 자재 부족이 예상되는
부품 목록과 부족 수량을 미리 확인하고 싶다,
So that 자재 부족으로 인한 공정 대기를 예방할 수 있다.
```

- 세부 요건
  - 예측 기준: 확정 작업지시 소요량 vs 현재 재고+입고 예정
  - 경보 색상: 부족(빨강), 주의(노랑), 충분(초록)
  - 구매 요청으로 원클릭 전환 기능

### Epic 3. FAT (공장 인수 시험) 관리

**Epic 목적:** 종이 체크리스트를 완전 디지털화하고, AI가 과거 FAT 데이터를 분석하여 반복 불량 패턴을 사전 식별한다.

---

**US-3-01. 디지털 FAT 체크리스트 작성 및 실행**

```
As a 품질담당자,
I want to 고객사·설비 유형별 FAT 체크리스트 템플릿을 시스템에서
선택하고, 태블릿으로 항목별 OK/NG와 측정값을 입력하고 싶다,
So that 현장에서 종이 없이 FAT를 완료하고 즉시 결과 리포트를 출력할 수 있다.
```

- 세부 요건
  - 체크리스트 항목: 기능시험, 안전시험, 성능시험 카테고리 구분
  - 측정값 입력: 숫자 입력 + 합불 판정 기준값 자동 비교
  - 사진 첨부 기능 (NG 항목 필수)
  - 오프라인 모드 지원 (인터넷 불안정 현장 대비)

---

**US-3-02. FAT AI Agent — 불량 원인 분석 및 대책 제안**

```
As a 품질담당자,
I want to FAT에서 NG 항목이 발생했을 때 AI Agent에게
"이 불량의 원인과 대책이 무엇인가요?"라고 질문하면
과거 유사 사례 기반의 답변을 받고 싶다,
So that 경험 부족한 담당자도 빠르게 원인 분석과 조치를 취할 수 있다.
```

- 세부 요건
  - RAG 기반: 과거 FAT 데이터, 설비 매뉴얼, 불량 이력 벡터 인덱싱
  - 응답 형식: 원인 Top-3 + 근거 문서 링크 + 권장 대책
  - 응답 시간: 10초 이내
  - 피드백 버튼(유용함/유용하지 않음)으로 모델 개선 데이터 수집

---

**US-3-03. FAT 결과 자동 리포트 생성**

```
As a PM,
I want to FAT 완료 후 고객사 제출용 품질 성적서를
시스템이 자동으로 생성해 주기를 원한다,
So that 납품 직전 문서 급조 작업을 없애고 고객 신뢰도를 높일 수 있다.
```

- 세부 요건
  - 포함 항목: 설비 정보, 시험 일시/장소, 항목별 결과, 측정값, 담당자 서명
  - 출력 포맷: PDF (고객사 로고·양식 커스터마이징 가능)
  - 다국어 지원: 한국어, 영어 (고객사 요구 시)

**US-3-04. 반복 불량 패턴 탐지 및 경보**

```
As a 품질담당자,

시스템이 자동으로 알림을 보내고 원인 분석 페이지를 열어주기를 원한다,
So that 반복 불량을 방치하지 않고 근본 원인 개선 활동을 즉시 시작할 수 있다.
```

- 세부 요건
  - 탐지 범위: 프로젝트 내, 설비 유형 내, 전사 단위 선택 가능
  - 트리거 조건: 동일 불량 코드 3회 이상 / 불량률 5% 초과
  - 자동 생성: 특별관리 불량 카드(8D Report 초안)

**US-3-05. FAT 일정 관리 및 고객 초청 알림**

As a PM,

### Epic 5. AI Agent (RAG + LangGraph)

**Epic 목적:** 제조 도메인 지식을 내재화한 AI Agent를 통해 비정형 질의 응답, 문서 생성, 의사결정 지원을 자동화한다.

---

**US-5-01. 제조 지식 Q&A Agent**

```
As a 현장작업자,
I want to 터치스크린 단말에서 "이 부품의 조립 순서가 어떻게 되나요?"
같은 질문을 자연어로 입력하면 AI가 관련 작업 표준서와 도면을 찾아
쉬운 말로 답변해 주기를 원한다,
So that 숙련자를 찾아다니지 않고도 작업 표준을 즉시 확인할 수 있다.
```

- 세부 요건
  - 지식 소스: 작업 표준서, BOM, FAT 이력, 설비 매뉴얼 (pgvector 인덱싱)
  - 응답에 출처 문서명·페이지 명시 (Hallucination 방지)
  - 한국어 자연어 입력 지원
  - 응답 시간: 15초 이내

---

**US-5-02. 견적 초안 자동 생성 Agent**

```
As a PM,
I want to 고객 RFQ(견적 요청서)를 시스템에 업로드하면
AI Agent가 유사 과거 프로젝트를 참조하여 견적 초안(BOM + 공수 + 원가)을
30~60분 내에 생성해 주기를 원한다,
So that 수작업으로 반나절 이상 걸리던 견적 작업을 대폭 단축할 수 있다.
```

- 세부 요건
  - 입력: PDF/Word RFQ 파싱 (LangChain Document Loader)
  - 유사 프로젝트 Top-5 참조 및 유사도 표시
  - 견적 항목: 재료비, 노무비, 외주비, 이익률 분리
  - 인간 검토·수정 후 확정 프로세스 필수

---

**US-5-03. 이상 알림 자동 리포트 Agent**

```
As a 경영진,
I want to 매일 오전 8시에 전일 생산 실적, 불량 현황, 납기 위험 프로젝트,
자재 부족 경보를 요약한 AI 리포트를 이메일로 받고 싶다,
So that 출근 전에 공장 전체 상황을 파악하고 우선순위 의사결정을 내릴 수 있다.
```

- 세부 요건
  - 스케줄: 평일 오전 08:00 자동 발송
  - 포함 항목: KPI 요약(불량률, 생산성, 납기율), 이슈 Top-3, 권장 조치
  - 포맷: HTML 이메일 + PDF 첨부

---

**US-5-04. 다단계 LangGraph Agent 워크플로 — 불량 원인 추적**

```
As a 품질담당자,
I want to 불량 발생 시 "이 불량의 5-Why 분석을 도와줘"라고 요청하면
AI Agent가 관련 공정 데이터, 설비 이력, 작업자 정보를 자동 수집하고
5-Why 분석 초안을 작성해 주기를 원한다,
So that 원인 분석에 필요한 데이터 수집 시간을 80% 단축할 수 있다.
```

- 세부 요건
  - LangGraph 멀티 스텝: 데이터 수집 → 패턴 분석 → 가설 생성 → 검증 → 요약
  - 각 단계 중간 결과 사용자에게 실시간 표시 (스트리밍)
  - 최종 출력: 수정 가능한 5-Why 표 + 개선 권고

---

**US-5-05. Agent 신뢰도 모니터링 및 피드백 루프**

```
As a 품질담당자,
I want to AI Agent 응답에 대해 정확도 평가(1~5점)와 코멘트를
남길 수 있고, 시스템이 낮은 평점 응답을 자동으로 수집하여
모델 개선에 활용하길 원한다,
So that AI 정확도 90% 목표를 체계적으로 달성하고 유지할 수 있다.
```

- 세부 요건
  - 평가 UI: 응답 하단 별점(1~5) + 자유 텍스트
  - 평점 3점 이하: 관리자 검토 큐 자동 등록
  - 월간 AI 정확도 리포트 (관리자 대시보드)
