## 공통 디자인 원칙

- **색상 체계:** 다크 네이비(#0D1B2A) 기반 + 포인트 시안(#00D4FF) — 공장 현장의 낮은 조도 환경에서 가독성 확보
- **폰트 계층:** 제목 20px Bold / 본문 14px Regular / 수치 강조 24px Bold Mono
- **그리드:** 12컬럼 / 사이드바 240px 고정 / 컨텐츠 영역 유동
- **반응성:** 현장 태블릿(1024px) ~ 사무용 모니터(1920px) 대응
- **접근성:** 색맹 대비 아이콘+텍스트 이중 표현, 주요 수치 배경 대비비 AA 이상

### 주요 컴포넌트

| 컴포넌트 | 설명 |
|----------|------|
| KPI 카드 4종 | 생산달성률/불량률/OEE/납기준수율 — 목표 대비 현재값과 전일 대비 증감 표시 |
| 진행 프로젝트 테이블 | 고객사별 프로젝트 납기 및 진척률 인라인 바 — 한눈에 포트폴리오 위험 파악 |

| AI 에이전트 상태 | 사이드바 하단 — 예측AI/RAG AI/FAT AI 각 서비스 헬스 실시간 표시 |
| 설비 미니 카드 | OPC-UA/MQTT 연결 4대 설비의 가동 상태를 색상 신호등으로 즉시 인지 |

### UX 결정 이유

- KPI 카드 상단 고정: 경영진과 생산관리자가 진입 즉시 "공장이 잘 돌아가고 있나?"를 3초 내 판단할 수 있어야 하기 때문
- AI 알림 피드 우하단 배치: F자형 시선 흐름에서 KPI → 프로젝트 확인 후 최종적으로 AI 경고를 처리하는 자연스러운 워크플로 유도
- 사이드바 AI 상태 상시 노출: AI 의존도가 높은 시스템이므로 서비스 다운 여부를 작업 도중 수시로 확인 가능해야 함

| Rev 비교 기능 | 드롭다운으로 두 리비전 선택 후 diff 뷰 — 변경 전후 원가 영향 산출 |

### UX 결정 이유

- 트리+상세 2분할 레이아웃: 계층 탐색과 상세 확인을 화면 전환 없이 동시 수행 — Excel의 여러 탭 전환 문제 해소
- 변경 이력 하단 고정 노출: BOM 변경이 원가에 즉각 영향을 주는 업종이므로 이력 투명성을 UX 레벨에서 강제
- 유사부품 AI 검색 버튼: 설계자가 신규 부품 등록 시 중복 코드 생성을 AI가 사전 방지 — 부품 코드 파편화 문제 해결

| 원가 구성 테이블 | AI 예측을 자재/인건/외주/경비/이익 5항목으로 분해 — 어디서 견적이 형성됐는지 투명화 |
| 유사 프로젝트 패널 | RAG로 검색된 과거 유사 프로젝트 3건 비교 — PM이 AI 예측의 합리성을 스스로 검증 |
| PM 조정 패널 | AI 예측값을 베이스로 PM이 특이사항 반영해 수동 조정 가능 — 최종 책임은 PM에게 |

### UX 결정 이유

- 신뢰도 수치 전면 표시: 경영진과 PM이 AI 견적을 그대로 사용할지 조정할지 판단하는 핵심 근거 — 블랙박스 AI 거부감 해소
- SHAP 설명 차트 나란히 배치: "왜 이 금액인가?" 질문에 즉시 답변 — 고객사 협상 시 근거 자료로 활용 가능
- PM 조정 영역 분리: AI 예측과 인간 판단을 명확히 구분 — 과도한 AI 의존 방지 및 책임 소재 명확화
- 4단계 스텝퍼: 견적 생성을 입력→분석→검토→발송 단계로 구조화 — 30~60분 목표 달성을 위한 프로세스 가이드
