# Akos AI MES — 문제 정의

## 현재 운영 현황 (AS-IS)

아코스는 자동차·2차전지·FPD 반도체용 자동화 설비를 수주 생산하는 방식으로 운영된다.
프로젝트마다 고유한 사양과 BOM이 존재하고, 설계·생산·납품이 분리된 채 관리되고 있다.

---

## 핵심 문제 영역

### 1. 설계/BOM 관리 — Excel 의존
- CAD/PDM 시스템에서 설계 도면·BOM을 개별 관리하나, MES와 연동 없음
- 설계 변경 시 BOM, 자재, 공정 데이터가 수동으로 업데이트됨
- 동일 부품이 프로젝트마다 다른 이름으로 등록되어 중복·혼선 발생
- BOM 오류로 인한 자재 수급 차질, 납기 지연 상시 발생

### 2. 생산/공정 관리 — 정보 단절
- 수주·설계·구매·제조·검사 데이터가 각각 별도 Excel 파일로 관리
- 여러 프로젝트 동시 진행 시 자재·인력 배분 정보를 실시간으로 파악 불가
- CNC, 선반, 밀링, MCT 설비의 OEE, 가동률, 불량률을 수집·분석하는 체계 없음
- 생산 일정 변경 시 관련 부서 간 수동 공유로 오류·지연 빈번

### 3. FAT (공장 인수 검사) — 수작업 기록
- FAT 결과(PASS/FAIL, 측정값, PLC 로그)를 종이·Excel에 기록
- 불합격 항목 발생 시 원인 분석 및 재작업 이력 추적이 어려움
- 동일 불량 패턴이 반복되어도 과거 데이터 기반 사전 예방이 불가능
- FAT 완료 후 고객 승인까지 소요 시간이 길고 예측 불가

### 4. 납품/SAT 관리 — 현장 피드백 단절
- 현장 설치(SAT) 데이터가 사내 시스템에 반영되지 않음
- 납품 후 발생하는 AS 이력, 부품 교체 기록이 설계 BOM과 연결되지 않음
- 고객사별 납품 실적·품질 이력을 체계적으로 관리하기 어려움

### 5. 원가/견적 — 경험 의존
- 견적 산출이 담당자 경험에 의존하여 정확도 편차가 큼
- 과거 유사 프로젝트 원가 데이터를 체계적으로 활용하지 못함
- 납기 예측 오차로 인한 공기 초과·패널티 리스크 상존

## 문제의 파급 효과

| 문제 영역 | 현재 지표 | 목표 |
|-----------|-----------|------|
| 불량률 | 427 ppm | 400 ppm (-6.3%) |
| 생산성 | 835 단위 | 780 단위 (-6.5% 불량 재작업) |
| 견적 생성 시간 | 수일 | 30~60분 |
| FAT 불량 재작업 | 기준 대비 높음 | 20% 이상 감소 목표 |

## 근본 원인 분석

```
[데이터 사일로]
  설계(CAD/PDM) ─┐
  생산(Excel) ───┼──▶ 통합 뷰 없음 ──▶ 의사결정 지연·오류
  품질(수기) ────┘

[AI 부재]
  과거 데이터 축적 없음 ──▶ 예측 불가 ──▶ 경험에 의존

[공정 추적성 없음]
  설계 ──▶ 생산 ──▶ FAT ──▶ SAT: 각 단계 데이터 단절
```

---

## 해결 방향

1. **데이터 통합 플랫폼** — MES를 중심으로 설계/생산/품질 데이터 단일화
2. **예측 AI** — 축적 데이터 기반 불량·납기·원가 예측 자동화
3. **AI Agent** — RAG 기반 지능형 어시스턴트로 현장 의사결정 지원
4. **전 공정 추적성** — BOM → 생산 → FAT → SAT → AS 이력 연결
