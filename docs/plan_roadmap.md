### Month 1 (2025.09): 인프라 · DB · Edge 연결

**목표:** 개발 기반 확립 및 실시간 데이터 파이프라인 가동

---

#### Sprint 1 (09.01 ~ 09.14) — 기반 인프라 구축

| 태스크 | 담당 | 산출물 |
|--------|------|--------|
| Docker Compose 구성 (FastAPI, PostgreSQL, Streamlit, Redis) | Infra | docker-compose.yml, .env 템플릿 |
| PostgreSQL 스키마 설계 및 마이그레이션 (Alembic) | BE | ERD, 초기 마이그레이션 파일 |
| RBAC 인증 시스템 구현 (JWT, 역할: PM/설계/생산/품질/현장/경영진) | BE | 인증 API, 권한 테이블 |
| CI/CD 파이프라인 구성 (GitHub Actions) | Infra | 자동 빌드/테스트 워크플로 |
| Excel BOM 데이터 분석 및 정규화 규칙 정의 | BE/PM | 데이터 매핑 문서 |
| Streamlit 앱 기본 프레임 (로그인, 사이드바, 라우팅) | FE | 앱 셸 |

**Sprint 1 완료 기준:**
- [ ] Docker 환경에서 FastAPI + PostgreSQL + Streamlit 정상 구동
- [ ] JWT 로그인 및 역할별 메뉴 분기 동작
- [ ] ERD 리뷰 완료 및 팀 승인

## 4. 마일스톤 및 Go/No-Go 기준

```
2025.09.01  ── Kickoff & 환경 구성 시작
     │
2025.09.14  ── [M1] 인프라 기반 완료
     │           Go: Docker 환경 구동, 인증 시스템 동작
     │           No-Go: OPC-UA 설비 접근 불가 시 Edge 범위 재협의
     │
2025.09.28  ── [M2] 데이터 마이그레이션 완료
     │           Go: Excel BOM 100% 이전 + 설비 데이터 수집 1개 이상
     │           No-Go: 데이터 정합성 오류율 5% 초과 시 ETL 재설계
     │
2025.10.14  ── [M3] 생산 관리 모듈 완료
     │           Go: 작업지시 전 사이클 + OEE 실시간 계산
     │           No-Go: 핵심 API 응답 2초 초과 시 아키텍처 검토
     │
2025.10.28  ── [M4] 품질·FAT·견적 모듈 완료  ← 중간 Go/No-Go 게이트
     │           Go: FAT 현장 테스트 통과 + 견적 60분 이내
     │           No-Go: 현업 수용도 50% 미만 시 UX 재설계 Sprint 추가
     │
2025.11.14  ── [M5] AI 모델 통합 완료
     │           Go: 예측 정확도 85% 이상 (내부 검증)
     │           No-Go: 정확도 75% 미만 시 모델 변경 또는 피처 재설계
     │
2025.11.30  ── [M6] 최종 Go-Live  ← 최종 Go/No-Go 게이트
                 Go: KPI 전항목 달성 + UAT 95% 합격
                 No-Go: 핵심 KPI 미달 시 30일 안정화 연장
```

### Go/No-Go 세부 판단 기준표

| 게이트 | Go 조건 | No-Go 조건 | 대응 방안 |
|--------|---------|-----------|---------|
