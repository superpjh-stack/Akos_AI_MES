## 1. 리스크 등록부 (Risk Register)

> **범례**
> - 발생가능성: 상(H) / 중(M) / 하(L)
> - 영향도: 상(H) / 중(M) / 하(L)
> - 위험지수 = 발생가능성 × 영향도 (H×H=9, H×M=6, M×M=4, M×L=2, L×L=1)

## 2. 데이터 품질 리스크 — Excel 마이그레이션 이슈

### 2-1. 현황 진단

아코스의 현재 데이터는 다음 구조적 문제를 내포하고 있다.

```
[현재 데이터 분산 구조]
BOM Excel (담당자별 개별 관리)
  ├── 설계자 A: BOM_rev3_final_진짜최종.xlsx
  ├── 설계자 B: BOM_2024_수정본.xlsx
  └── PM: BOM_통합_v2.xlsx  ← 실제 어떤 것이 최신인지 불명확

생산실적 Excel (월별 시트 분리)
  └── 2024_생산실적.xlsx (12개 시트, 시트별 컬럼명 불일치)

FAT 체크리스트 (고객사별 Word/Excel 혼용)
  └── 표준화 없음, 담당자 퇴직 시 데이터 유실 이력 존재
```

### 2-2. 마이그레이션 리스크 상세

| 이슈 유형 | 구체적 문제 | 발생 확률 | 해결 방안 |
|-----------|-------------|-----------|-----------|
| **중복 데이터** | 동일 품번이 여러 Excel에 다른 규격으로 기입 | 매우 높음 | 마스터 데이터 소유자 1인 지정, 골든 레코드 정책 수립 |
| **결측값** | 자재코드, 단가, 납기일 공란 | 높음 | 결측률 30% 초과 시 해당 레코드 별도 검토 큐 이관 |
| **비표준 날짜 형식** | '24.03.05', '2024-03-05', '24년3월5일' 혼재 | 높음 | 정규식 파서 + 사람 검토 2중 체계 |
| **단위 불일치** | 수량 단위 EA/개/pcs 혼용, 중량 kg/g 혼용 | 중간 | 단위 표준화 테이블 사전 정의 후 매핑 자동화 |
| **버전 관리 부재** | 어느 Excel이 최신 버전인지 불명확 | 매우 높음 | 파일 수정일 기준 최신본 선별 + 현업 확인 서명 |
| **자유 텍스트 오기입** | 품명 한글/영문/약어 혼용 (예: '볼트' / 'BOLT' / 'BLT') | 높음 | 유사도 매칭(Fuzzy Matching) 알고리즘 적용 |
| **계산식 셀 의존성** | Excel 수식 참조 셀이 마이그레이션 시 깨짐 | 중간 | 수식 대신 계산 결과값(Value)만 추출하여 DB 적재 |

### 2-3. 데이터 마이그레이션 4단계 프로세스

```
Phase 0: 데이터 인벤토리 (1주)
  └── 전사 Excel 파일 전수 조사 → 목록화 → 오너십 지정

Phase 1: 데이터 프로파일링 (1주)
  └── Pandas Profiling / Great Expectations 활용
      → 결측률·중복률·이상치 통계 리포트 생성

Phase 2: 클렌징 & 변환 (2주)
  └── 자동화 스크립트 + 현업 키맨 수동 검토
      → 클렌징 전후 레코드 수 및 품질 지표 비교

Phase 3: 검증 & 적재 (1주)
  └── PostgreSQL 적재 → 비즈니스 룰 검증 쿼리 수행
      → 현업 담당자 샘플링 검토 서명
```

### 2-4. 데이터 품질 허용 기준

| 지표 | 목표 기준 | 최소 허용 기준 |
|------|-----------|----------------|
| 결측률 | 5% 이하 | 15% 이하 |
| 중복률 | 0% | 1% 이하 |
| 형식 오류율 | 0% | 0.5% 이하 |
| AI 학습 가용 데이터 | 80% 이상 | 60% 이상 |

## 3. 외부 시스템 연동 리스크 — PDM/ERP/PLC 연동 위험

### 3-1. 연동 대상 시스템 현황

| 시스템 | 현재 상태 | 연동 방식 | 리스크 수준 |
|--------|-----------|-----------|-------------|
| PLC (설비 제어) | 제조사 혼재 (Siemens/Mitsubishi 등) | OPC-UA, MQTT | 높음 |
| 기존 ERP (추정) | 미도입 또는 단순 회계 패키지 | Excel/CSV Export | 중간 |
| PDM (도면관리) | 미도입, 파일서버 관리 | 파일 직접 접근 | 중간 |
| 고객사 포털 | 납기·발주 정보 웹 조회 | 수동 입력 또는 API | 낮음 |

### 3-2. PLC 연동 리스크 상세

```
[리스크 시나리오]
1. 프로토콜 비호환
   - Siemens S7: OPC-UA 기본 지원 (상대적으로 안전)
   - Mitsubishi Q시리즈: 자체 SLMP 프로토콜 → OPC-UA 게이트웨이 필요
   - 구형 설비: RS-232C 시리얼 통신만 지원 → 변환 모듈 추가 비용 발생

2. 실시간성 보장 실패
   - MQTT QoS 0(Fire-and-forget) 사용 시 데이터 손실
   - 대응: QoS 1 이상 + 로컬 버퍼링 + 재전송 로직 필수

   - 일부 PLC 제조사는 제3자 연동 보증 거부
   - 대응: 설비 인수 계약서에 OPC-UA 지원 조항 추가 (신규 구매분)
```

## 5. KPI 측정 방법론

### 5-1. 불량률 측정 방법론

#### 정의
> **불량률** = (불량 발생 건수 / 전체 생산 수량) × 100 (%)

#### 측정 상세 방법

```sql
-- MES DB 기준 불량률 산출 쿼리 예시
SELECT
    production_date,
    project_code,
    COUNT(*) FILTER (WHERE defect_flag = TRUE) AS defect_count,
    COUNT(*) AS total_production,
    ROUND(
        COUNT(*) FILTER (WHERE defect_flag = TRUE)::DECIMAL
        / COUNT(*) * 100, 2
    ) AS defect_rate_pct
FROM production_records
WHERE production_date BETWEEN :start_date AND :end_date
GROUP BY production_date, project_code
ORDER BY production_date;
```

| 항목 | 내용 |
|------|------|
| **측정 주기** | 일별 집계, 주별/월별 추세 분석 |
| **기준선 수립** | 시스템 오픈 전 과거 3개월 Excel 데이터 소급 집계 |
| **측정 범위** | 내부 공정 불량 + 고객 반품(외부 불량) 분리 집계 |
| **불량 분류** | 공정별(가공/조립/검사), 원인별(설계/자재/작업오류) |
| **목표 달성 판정** | 기준선 대비 6.3% 이상 감소 시 달성 |
| **시각화** | Streamlit 대시보드 - 파레토 차트 + 추세선 |

#### 주의사항
- 과거 Excel 데이터 기준선은 동일한 정의와 범위로 소급 계산
- 시즌성(납기 집중 시기) 보정 필요 시 동기 대비 비교 방식 병행

### 5-2. 생산성 측정 방법론

#### 정의
> **생산성 지수** = 실제 생산량 / (투입 공수 × 표준 시간)
>
> 또는 리드타임 기준: **생산 리드타임** = 작업 시작일 ~ 출하일 (영업일 기준)

#### 측정 상세 방법

| 항목 | 내용 |
|------|------|
| **1차 지표** | 프로젝트별 생산 리드타임 (착수일 ~ 출하일) |
| **2차 지표** | 작업자 1인당 일일 처리 공수 (작업 로그 기반) |
| **3차 지표** | 설비 가동률 (OPC-UA 수집 데이터 기반) |
| **측정 주기** | 프로젝트 완료 시점 집계 + 주별 추세 |
| **기준선 수립** | 과거 6개월 평균 프로젝트 리드타임 |
| **목표 달성 판정** | 리드타임 6.5% 단축 또는 처리량 6.5% 증가 |

```
[생산성 측정 데이터 소스]
OPC-UA 수집 → 설비 가동/정지 시간 자동 기록
작업자 MES 입력 → 공정 착수/완료 시간 기록
프로젝트 모듈 → 전체 리드타임 자동 산출
```
